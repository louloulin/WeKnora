九、v0.7.26 详细设计：公式 / Rollup / Linked Record 引擎

9.1 目标

  • 在多维表 (#26) 上提供 类型安全的表达式引擎，支持跨行/跨表计算（Rollup）、跨表关联（Linked Record）、自定义公式（Formula）。
  • 对标 Notion formula 2.0（函数式 + 类型系统）+ 飞书智能公式（中文函数 + AI 字段）+ Tana Live Nodes（实时计算）。
  • 为 v0.7.27 Automation 提供"事件源"，为 v0.7.29 知识图谱提供"属性值"。

9.2 数据模型

// 新增迁移 000132_formula_engine.up.sql

CREATE TABLE formula_expressions (
    id              BIGSERIAL PRIMARY KEY,
    tenant_id       TEXT NOT NULL,
    kb_id           TEXT NOT NULL,
    database_id     BIGINT NOT NULL,
    column_id       BIGINT NOT NULL,
    expr_text       TEXT NOT NULL,            -- 例如 "rollup('Total', sum, related('line_items.price'))"
    expr_ast        JSONB NOT NULL,           -- 解析后的 AST
    result_type     TEXT NOT NULL,            -- 'number' | 'string' | 'date' | 'bool' | 'list'
    version         INT NOT NULL DEFAULT 1,
    created_by      BIGINT NOT NULL,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE formula_dependencies (
    id              BIGSERIAL PRIMARY KEY,
    formula_id      BIGINT NOT NULL REFERENCES formula_expressions(id) ON DELETE CASCADE,
    depends_on      JSONB NOT NULL,           -- {column_id, database_id, kind: 'column'|'row'|'related'}
    seq             INT NOT NULL DEFAULT 0
);

CREATE INDEX idx_formula_expr_db_col ON formula_expressions(database_id, column_id);
CREATE INDEX idx_formula_deps_formula ON formula_dependencies(formula_id);

number := int | float | number + number | number - number | number * number | number / number
string := '"' chars '"' | concat(string, string) | upper(string) | lower(string)
bool   := true | false | number == number | number < number | and(bool, bool) | or(bool, bool)
date   := now() | date_add(date, int, 'day') | date_diff(date, date, 'day')
list   := related('column_path') | filter(list, lambda) | map(list, lambda)
rollup := rollup('target_column', aggregate, list)  // aggregate = sum | avg | count | min | max
if     := if(bool, any, any)
link   := link('other_database', 'match_column', 'value')

CREATE TABLE supertags (
    id              BIGSERIAL PRIMARY KEY,
    tenant_id       TEXT NOT NULL,
    kb_id           TEXT NOT NULL,
    name            TEXT NOT NULL,
    color           TEXT,
    schema          JSONB NOT NULL,           -- [{name, type, required}]

CREATE TABLE entities (
    id              BIGSERIAL PRIMARY KEY,
    tenant_id       TEXT NOT NULL,
    kb_id           TEXT NOT NULL,
    supertag_id     BIGINT REFERENCES supertags(id),
    name            TEXT NOT NULL,
    properties      JSONB NOT NULL DEFAULT '{}',
    embeddings      BYTEA,                    -- pgvector 风格
    first_seen_doc  BIGINT,
    last_seen_doc   BIGINT,
    occurrence      INT NOT NULL DEFAULT 1,
    trust_score     REAL NOT NULL DEFAULT 1.0,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE TABLE entity_relations (
    id              BIGSERIAL PRIMARY KEY,
    src_entity_id   BIGINT NOT NULL REFERENCES entities(id) ON DELETE CASCADE,
    dst_entity_id   BIGINT NOT NULL REFERENCES entities(id) ON DELETE CASCADE,
    relation        TEXT NOT NULL,
    weight          REAL NOT NULL DEFAULT 1.0,
    evidence_docs   JSONB NOT NULL DEFAULT '[]',   -- 支撑文档 IDs
    confidence      REAL NOT NULL DEFAULT 1.0,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (src_entity_id, dst_entity_id, relation)
);

CREATE INDEX idx_entities_tenant_kb ON entities(tenant_id, kb_id);
CREATE INDEX idx_entities_supertag ON entities(supertag_id);
CREATE INDEX idx_relations_src ON entity_relations(src_entity_id);
CREATE INDEX idx_relations_dst ON entity_relations(dst_entity_id);

12.3 抽取管道

  1. 实体识别（NER）：使用 LLM（GPT-4o / DeepSeek / Doubao）做 zero-shot NER，输入文档段落，输出实体列表
  2. 关系抽取（RE）：对每对共现实体，用 LLM 判断关系类型 + 置信度
  3. 实体合并：向量相似度 ≥ 0.92 触发实体合并（保留 trust_score 较高的）
  4. 超标签绑定：根据实体类别自动建议超标签，管理员确认后绑定

十三、v0.7.30 详细设计：多地域容灾 + 数据驻留

13.1 目标

  • 多地域：WeKnora 服务可部署在多个地理区域（CN / HK / US / EU / SG），租户可选择主地域
  • 数据驻留：标记 data_residency=CN|EU|US|...，强约束租户数据不出境

  • 故障切换：健康检查失败后 DNS 切换 + 读写切到备用地域（RTO ≤ 60s）
