# v0.7.17 — AI Assistant 前端面板 · 实施计划

> 目标：把 v0.7.15 后端检索 + v0.7.16 GeoIP 后的检索，包装成飞书 / Notion / Glean 同级别的问答 UI。

## 一、范围

1. **侧栏面板（嵌入式）**：Wiki / KB 文档详情页右侧常驻面板。
2. **独立 Chat 页**：KB 顶部 / 全局命令面板 ⌘K 唤起。
3. **流式输出**：SSE 通道，answer 边生成边渲染；引文先到位再渲染 answer。
4. **多轮对话**：<span class="ref">conversation_id</span> 在面板 sessionStorage 保留 30 分钟；超期自动开新会话。
5. **反馈循环**：每条回答下方 👍 / 👎 / ⚠️ 引文不准确，审计入 assistant_feedback 表。

## 五、风险

1. **流式 + 引文顺序**：引文先到位再渲染 answer 需要 SSE 协议改造，可能要重新设计后端事件形状。
2. **大文档块**：KB chunk 平均 512 token，HNSW top-10 检索 → 引文 10 段；折叠展开性能。
3. **LLM 延迟**：同步阻塞会卡 3-5s；流式是必需的；前端要有 loading skeleton。

## 六、交付物

- 6 个新文件 / 2 个修改文件 / 1 个迁移 / 1 个测试集（>20 用例）
- e2e smoke：启动 → 选 KB → 输入问题 → 流式渲染 → 引文点击展开 → 👍 → 历史拉取
- 性能基线：首 token ≤ 1.5s（流式）+ 平均延迟 ≤ 3.5s（5 KB + 5 wiki 引用）
