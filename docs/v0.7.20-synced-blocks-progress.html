三、数据模型

-- 迁移 112 (Postgres) / 028 (SQLite): wiki_sync_blocks
CREATE TABLE wiki_sync_blocks (
    id              BIGSERIAL    PRIMARY KEY,
    tenant_id       BIGINT       NOT NULL,
    kb_id           VARCHAR(36)  NOT NULL,
    block_id        VARCHAR(36)  NOT NULL,    -- canonical UUID, stable across renames
    title           VARCHAR(256) NOT NULL DEFAULT '',
    content_json    TEXT         NOT NULL DEFAULT '{}',  -- ProseMirror/Tiptap JSON
    content_md      TEXT         NOT NULL DEFAULT '',     -- Markdown projection
    version         BIGINT       NOT NULL DEFAULT 1,      -- auto-increment on update
    owner_id        BIGINT       NOT NULL,
    created_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    UNIQUE (tenant_id, block_id)
);

-- 迁移 113 (Postgres): wiki_sync_block_refs
CREATE TABLE wiki_sync_block_refs (
    id              BIGSERIAL    PRIMARY KEY,
    tenant_id       BIGINT       NOT NULL,
    kb_id           VARCHAR(36)  NOT NULL,
    block_id        VARCHAR(36)  NOT NULL,
    page_id         VARCHAR(36)  NOT NULL,
    anchor_slug     VARCHAR(256) NOT NULL DEFAULT '',
    content_version BIGINT       NOT NULL DEFAULT 0,
    rendered_at     TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    created_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    UNIQUE (tenant_id, block_id, page_id, anchor_slug)
);

关键设计：canonical 与 ref 分离，一次编辑全局生效（fan-out 通过 service.SyncPageRefs 在每次 page save 时重写 refs + MarkRendered 同步 content_version）。

七、风险与对策

风险等级缓解
前端渲染层未接 Tiptap中v0.7.20.x 增加 Tiptap SyncBlock 节点，扫描 [[sync:UUID]] 渲染为锁定 chip + edit-source 按钮
实时态推送未联调中复用 v0.7.19 Yjs WS Hub 的 page-channel，订阅 sync_block:<UUID> 频道广播 canonical 变更
大文档 fan-out 性能低refs 写入走批量 INSERT OR REPLACE，单 page ≤ 50 个 ref 时延迟可忽略
权限继承边界低sync block 跟随 KB ACL（tenant_id + kb_id），不走 page 级 ACL（避免越权）
