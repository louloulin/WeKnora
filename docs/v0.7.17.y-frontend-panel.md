## 能力

- SSE 流式消费：metadata → citation × N → token × N → done
- Citation 卡片：KB / Wiki 双 kind 徽章，点击触发 `open-citation` 事件
- 引文内联：[KB: title] / [Wiki: title] 渲染为可点击 chip
- 中途停止：AbortController + 按钮切换
- 多 turn：本地 sessionStorage（panel state 自管）
- 错误处理：transient → 提示；permanent → 重试按钮
- 折叠：collapsed prop 控制右侧栏
- 国际化：zh-CN + en-US（按需扩 ko-KR / ru-RU）

## 设计决策

1. **零外部依赖**：除既有的 `axios`、`@microsoft/fetch-event-source`、`tdesign-vue-next`，不引入新包
2. **AbortSignal via fetchEventSource**：浏览器 EventSource 不支持 POST body + 自定义 header，所以走 fetch + SSE 流式解析
3. **Citation 内联引用**：后端 system prompt 指引 LLM 输出 `[KB: ...]`，前端解析为可点击 chip（与 Notion AI Q&A 的 [1] / [2] 同档体验）
4. **collapsed prop**：复用同一组件支持侧栏收起 + 完全隐藏两态
5. **i18n 注入**：`useI18n()` 取全局 translator，避免组件内嵌翻译
6. **事件驱动**：所有外部交互走 `defineEmits`（open-citation / open-history / toggle-collapse），父组件决定如何处理
