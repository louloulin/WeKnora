Kubernetes 部署指南

最近更新 2026-08-29 by 王晓 · 关联 KB：工程标准库 / Helm Chart 参考

本文档描述 WeKnora 在生产环境的 Kubernetes 部署流程，包含 Helm Chart 参数说明、持久化存储配置、HPA 扩缩容策略以及升级回滚步骤。

1. 前提条件

部署前需要准备：

  • Kubernetes 1.28+ 集群（支持 PDB 与 PodDisruptionBudget v1）
  • Helm 3.13+ 与 kubectl 1.28+
  • 已配置的 PostgreSQL 15 / Redis 7 / Qdrant 向量库
  • 对象存储（MinIO 或 S3 兼容）

2. Helm 安装

标准部署使用 Helm Chart weknora-stack-1.2.0。其中数据库、缓存、向量库均通过外部依赖提供，避免 StatefulSet 重建时的数据风险。

3. 持久化存储

上传的原始文档和解析后的 chunk 通过 weknora-uploads PVC 持久化，容量建议 ≥ 500 GiB（生产环境 ≤ 100 万文档）。

WeKnora 在 K8s 里跑的时候，文档上传到 PVC 还是对象存储更好？
AI 助手 · 引用 3 篇
根据知识库内容，混合方案是推荐做法：
  • 原始上传文件 → 对象存储（MinIO / S3），便于跨节点访问 + 生命周期管理
  • 解析后的 chunk + 向量 → PostgreSQL + Qdrant，向量化后无状态
  • 运行期临时文件 → emptyDir 即可

  • minReplicas=3，maxReplicas=20
  • CPU 利用率阈值 65%
