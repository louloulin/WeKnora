# WeKnora WCAG 2.2 AA Audit & Migration Plan — Build #34.x

> Status: in-progress (v0.7.32, Build #34.x)
> Target compliance: WCAG 2.2 Level AA · Section 508 · EN 301 549

## 1. Current state (v0.7.32)

The WeKnora frontend ships with:

- TDesign Vue Next design tokens (`frontend/src/assets/theme/theme.css`)
- Light + dark themes via `[theme-mode="dark"]` attribute
- Reactive `useTheme()` composable with `light | dark | system` modes
- 125 page views + 113 components

**Gap vs WCAG 2.2 AA:**

| Principle | Guidelines | Status | Notes |
|---|---|---|---|
| Perceivable | 1.1.1 Non-text Content | ⚠️ partial | Manual review needed for plugin icons / chart images |
| Perceivable | 1.3.1 Info & Relationships | ⚠️ partial | Some inline tables missing `<th scope>` |
| Perceivable | 1.4.3 Contrast (Min) | ✅ | TDesign tokens tuned to AA |
| Perceivable | 1.4.11 Non-text Contrast | ⚠️ partial | Focus ring contrast on dark theme TBD |
| Operable | 2.1.1 Keyboard | ⚠️ partial | Editor toolbar not fully keyboard-navigable |
| Operable | 2.4.7 Focus Visible | ✅ | TDesign focus ring on all interactive elements |
| Operable | 2.5.8 Target Size | ⚠️ partial | Sidebar nav items < 24×24 CSS pixels in some views |
| Understandable | 3.3.2 Labels | ⚠️ partial | Search input has placeholder but no `aria-label` |
| Robust | 4.1.2 Name, Role, Value | ⚠️ partial | Custom TipTap nodes missing role announcements |

## 2. Automated audit pipeline (planned)

Add to `frontend/package.json`:

```json
{
  "devDependencies": {
    "@axe-core/playwright": "^4.10.0",
    "axe-core": "^4.10.0"
  },
  "scripts": {
    "test:a11y": "playwright test --grep @a11y"
  }
}
```

Per-route test scaffold (`frontend/tests/a11y/wiki-page.spec.ts`):

```ts
import { test, expect } from '@playwright/test'
import AxeBuilder from '@axe-core/playwright'

test.describe('@a11y wiki page', () => {
  test('passes WCAG 2.2 AA', async ({ page }) => {
    await page.goto('/wiki/example')
    const results = await new AxeBuilder({ page })
      .withTags(['wcag2a', 'wcag2aa', 'wcag22aa'])
      .analyze()
    expect(results.violations).toEqual([])
  })
})
```

CI integration (`.github/workflows/a11y.yml`):

```yaml
name: a11y
on: [pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - run: npm ci
      - run: npm run build
      - run: npm run test:a11y
```
