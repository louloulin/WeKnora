四、文档↔知识库一体化（Doc-KB Integration）

用户的真实工作流是：写文档 → 提到知识库 → 在文档里被 RAG 引用 → 实时更新。现有 WeKnora 的 Doc↔KB Bridge（v0.7.23）已实现 wiki↔KB 引用自动 reconcile，但完整闭环还需要在以下 7 个层面打通：

① 双向引用（DB-Backed）

文档中提到 KB 条目时自动生成 link；KB 条目被文档引用时显示在"被引用"面板。

v0.7.23 wiki↔KB 引用 reconcile P1 v0.7.25 双向 link 面板

② 文档 → KB 自动摘要

文档发布时异步触发 chunk → enrich → KB ingest；高频词/核心概念作为 KB 实体。

v0.7.23 框架已留 hook P0 v0.7.24.x 接入 enrich

③ KB → 文档反向注入

KB 检索结果可以直接拖拽到文档形成引用块；引用块版本化（KB 更新后文档自动同步）。

未实现 P1 v0.7.26

④ 共享标签 / 分类

文档和 KB 条目共享标签体系（v0.7.21 wiki_tag 已存在）；搜索可同时检索两类。

tag 体系已建 P1 跨类型 search

⑤ 统一权限视图

用户在"我的工作台"看到所有可访问的文档、KB 条目、Agent；权限继承自 AuthZ 复合决策。

AuthZ 已具备 P1 v0.7.26 工作台聚合视图

⑥ 跨源类型搜索

一次搜索同时返回 wiki pages / KB chunks / database rows / agents / chat 历史。

search v2 已扩展 P1 跨源聚合结果页

⑦ AI 工作流（Notion AI / Feishu 智能伙伴）

选中段落 → "总结 / 翻译 / 改写 / 提取任务 / 生成表格" 直接落地为 KB 条目或 agent 输入。
