一、执行摘要

WeKnora 已经从 RAG Demo 演进为覆盖知识库、Wiki、智能体、共享空间、RBAC、审计、缓存、批处理和评测的产品平台。核心 RAG 链路与 Wiki 协作能力已经成熟，企业级身份（OIDC/Casdoor）、多模态（ASR/VLM）、多向量库（10 后端）、多 LLM（17+）、多 IM（8 平台）也已经形成完整矩阵。当前最关键的差距集中在三个方向：

1. 企业级 IAM 与 AuthZ

关系型 AuthZ 抽象 phase-3 已落地（internal/authz/：KB / WikiPage / Agent / Datasource 适配器 + 容器注入 KB Share / WikiAcl / Agent Service + 37/37 测试全绿）。企业级 IAM 双轨并行：internal/samlsp/ 提供 SAML 2.0 SP（12/12 测试全绿）+ internal/handler/saml.go 暴露 metadata / login / ACS / IdP CRUD + 迁移 107 saml_idp_configs + 迁移 108 user_saml_federation_identities + LoginWithSAMLAssertion 完成 ACS→JWT 闭环。v0.7.9 启动 LDAP/AD connector（参照 SAML 双层对称设计）：internal/ldapsp/ 低层 Dial/Bind/Search（5/5 测试全绿）+ 迁移 110 ldap_configs + 迁移 111 user_ldap_federation_identities + LoginWithLDAPCredentials simple-bind 闭环 + LDAPHandler CRUD + test + admin list + 容器注入 LDAPLoginDeps。剩余 SCIM / MFA / Conditional Access / SLO。

phase-3 done

2. 通知与协作闭环
