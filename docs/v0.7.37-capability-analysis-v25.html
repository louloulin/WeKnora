1.1 三句话总结

战略位置

WeKnora 已经跨过 "功能" 门槛，但还没跨过 "体验" 和 "可信" 两道门槛。v0.7.37 拥有与 Notion/飞书 同级的 23 个产品模块（KB / Wiki / MindMap / Slides / Database / KG / Workflow / Connectors / Enterprise IAM / MCP / SDK ...），但在 18 个 P0 维度（移动端 / 离线 / 浏览器扩展 / 行业模板 / 合规证据 / ROI 仪表板 / 公共发布 / 妙记级 AI 视频转写 ...）上仍落后。

缺口分布
  • AI 体验 (5 P0) · Inline AI 不够智能 / 缺会议转写 / 缺内容摘要 / 缺 Knowledge Studio / 缺 AI Search 跨应用
  • 移动 + 离线 (3 P0) · 无 App · 无 PWA 离线 · 无断网编辑
  • 合规 + 治理 (3 P0) · 缺 SOC 2 / HIPAA 证据 · 缺 WORM 存储 · 缺 Admin 控制台
  • 生态 + 平台 (4 P0) · 无浏览器扩展 · 无 Public 站点 · 无 ROI · 无模板市场运营
  • 体验打磨 (3 P0) · 一键 Onboarding 缺 · 仪表板缺 · 国际化不完整
资源评估（v0.7.37 → v0.7.50 = 4 个月）

建议按 2 周 / Build 节拍推进 (#45-#50 共 6 Build × 2 周 = 12 周 + 4 周 buffer)，单 Build 资源需求 1-2 人月 (含代码 / 测试 / 文档 / 演示视频)，与 v22-v24 节奏保持一致。Build #46 合规需引入外部审计合作伙伴，是 v0.7.37-0.7.50 周期内最重的 Build。

1.2 为什么 v25 比 v24 更紧迫

2026-09 时点的关键窗口： Notion 2.0 (Mail/Calendar/Sites) 即将 GA、飞书 8.0 + 妙记升级已经放量、Rovo (Confluence AI) 正式商用、Loop 进入 GA。如果 WeKnora 在 2026-Q4 前不补齐移动端 + 合规 + 浏览器扩展 + 妙记同级 AI，会在 Enterprise 招投标中输给合规模块成熟的 Notion/Confluence，飞书在国内输给本地化深度。

v25 新增的竞品对照： 本版加入 Loop（微软的"文档画布"）、ClickUp Docs、Airtable Cobuilder、Document360 Edison AI、Guru 6.0、Slab 4、Tana 六位对手——它们代表 2026 知识管理的三大新趋势：(1) Canvas 型工作面 (Loop / Tana) (2) AI Search 跨应用 (Glean / Guru) (3) Verified Knowledge 是 GTM 卖点 (Document360 / Guru / Slab)。

2.1 Notion 2.0 — "Capture · Find · Automate" + Mail / Calendar / Sites 三件套

核心定位

从 "Workspace" 升级为 "AI Workplace OS" — Notion 2.0 (2026 H2) 把三个邻近场景 (Mail / Calendar / Sites) 拉进同一条产品线，全部挂在 Enterprise Search 之上。

2026 H2 新功能

  • Notion Mail — AI 邮件客户端，对接 Gmail / Outlook，AI 自动写回复 / 摘要 / 拆分主题 缺
  • Notion Calendar — AI 日程助手，与 Slack / Zoom 双向同步 缺
  • Notion Sites — 文档 → 对外公开站点（含 SEO / 自定义域名） 缺
  • Notion AI Agents · 6 大场景 (Onboard / Brainstorm / Weekly Report / Feedback Triage / Slack Resolver / Security Alert) 缺 Agent Builder UI
  • Cross-app Search · 90+ 应用集成 Build #30.x 15 个 connector 已做
  • Model Agnostic · 90+ LLM（OpenAI / Anthropic / Gemini / 自托管） 已支持多模型

关键差异 vs WeKnora

Workspace vs KnowledgeNotion 把 KB 当成另一个 Product；WeKnora 把 AI 当成 KB 的一等公民——所以 AI Search 这条路已经天然占优 (强)，但 Workspace shell (Mail / Calendar / Sites) 是 0。
