# v0.7.17 Prep — LLM Stream Package

> 配套 v0.7.17 AI Assistant 前端面板的「LLM 厂商无关」抽象。
> 这是把 v0.7.15 检索后端 + v0.7.17 前端面板 + 真实 LLM 接入之间的桥。

## 范围

1. **Provider 接口**：所有 LLM 厂商（OpenAI / Anthropic / 豆包 / Qwen / DeepSeek / 自托管）必须实现的最小契约。
2. **Request / Response / Event 类型**：assistant service 与 provider 之间的纯 Go 数据形状，与 wire 无关。
3. **EventSink 接口 + FuncSink 适配器**：让 provider 把流式事件推给 caller。
4. **NoopProvider**：与 v0.7.15 AssistantService.composeAnswerPlaceholder 等价的默认实现。
5. **FormatSSEEvent**：单事件 → SSE wire 帧（`event: token\ndata: {...}\n\n`）的纯函数 helper。
6. **ErrProviderUnavailable / ErrProviderTimeout + IsTransient()**：让 handler 把 transient 错误映射成 503 / 504。

## 接口设计

```go
type Provider interface {
    Complete(ctx context.Context, req Request) (Response, error)
    Stream(ctx context.Context, req Request, sink EventSink) error
    Name() string
}

type Event struct {
    Type EventType  // token | citation | done | error
    Data any        // typed payload
    Error error     // populated on EventError
}

type EventSink interface {
    OnEvent(Event) error
}
```
